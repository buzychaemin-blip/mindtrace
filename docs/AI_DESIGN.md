# 설명 가능한 마인드 코치

## 구현

현재는 LLM/학습 모델이 아닌 **규칙 기반 패턴 분석**입니다. 외부 AI 호출과 원시 사용 이력 전송은 하지 않습니다. 핵심 가설은 '사용 이유를 돌아보고 대안을 고르는 과정이 습관 개선을 도울 수 있다'이며, 효과는 아직 검증하지 않았습니다.

분석 기간은 브라우저 현지 날짜의 최근 7일입니다. 원본 가상 기록은 `demo`, 직접 추가한 기록은 `manual`이며 시연 모드의 분석에는 두 종류가 포함될 수 있습니다. 모든 화면 상단에 모드를 표시합니다.

## 규칙

| 신호 | 조건 | 근거/제안 |
|---|---|---|
| 저녁 무목적 사용 | 최근 7일 18시 이후 목적 사용을 제외한 기록 3회 이상 | 횟수/분 표시, 10분 스마트폰 없는 산책 제안 |
| 긴 디지털 사용 | 개별 기록 30분 이상 1회 이상 | 해당 횟수, 사용 전 종료 시점 정하기 |
| 긴 공부 세션 | 공부 세션 50분 이상 | 세션 수, 5분 스트레칭 제안. 중간 휴식 유무는 단정하지 않음 |
| 관찰 단계 | 기록은 있지만 위 조건 미충족 | 단정 대신 기록을 더 살펴보도록 안내 |
| 데이터 없음 | 사용·해당 공부 패턴 없음 | 결론과 위험 점수를 만들지 않음 |

제안은 수락/수정/완료/거절할 수 있습니다. 의학적 위험도, 정신 상태, 실제 기기 전체 이용량을 추정했다고 표시하지 않습니다.

## 웰빙 점수 rule-v1.0

- 무목적 사용 변화, 기본 가중치 0.35: 이전 7일과 현재 7일 모두 사용 기록이 있을 때 계산. `r = 현재 무목적 분 / 이전 무목적 분`, `점수 = clamp(100 - 50r, 0, 100)`. 이전 무목적 분이 0이면 현재도 0일 때 r=0, 그 외 r=2.
- 휴식 실천, 0.25: 휴식 횟수를 직접 기록한 날에 대해 `평균(min(휴식 횟수/3,1)) × 100`.
- 내 계획 실천, 0.20: 기간 중 날짜가 있는 할 일의 완료 비율 × 100.
- 취침 목표, 0.20: 기록한 날의 실천 비율 × 100.

최종 점수는 `round(Σ(존재하는 항목 값 × 기본 가중치) / Σ(존재하는 항목 가중치))`입니다. 모든 항목이 없으면 null/‘—’이며 0점이 아닙니다. **측정 범위**는 사용한 기본 가중치의 합을 %로 표시합니다. 이는 통계적 신뢰구간이나 정확도가 아닙니다.

공부 시간을 늘려 추가 점수를 받지 않습니다. 100점이 건강하다는 뜻이 아닙니다. 본인이 선택한 규칙의 참고 지표이며 경쟁 순위를 만들지 않습니다.

## 리포트

현재 7일과 바로 이전 7일의 기록 합계를 비교합니다. 이전 값이 없거나 0이면 변화율을 산출하지 않습니다. 미션 완료 수는 전체 기록 기준이라고 표시합니다. 시연 수치로 개선 효과나 연구 결과를 주장하지 않습니다. 주간 화면의 CSV는 기간 비교·점수 버전·측정 범위·14일간 일별 합계를 포함합니다. 설정의 JSON/CSV는 원자료이며 보고서의 영구 스냅샷 저장은 후속 기능입니다.

맞춤 계획은 남은 목표를 최대 25분 집중/5분 휴식 단위로 나누는 단순 제안입니다. 사용자의 실제 집중도나 성적을 측정한 계획 생성 AI는 아닙니다.
