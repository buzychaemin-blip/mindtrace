# 현재 제한 사항

## 완료한 웹 MVP

단계 A의 과목/타이머/계획/할 일/통계/수동 사용 기록/규칙 코치/미션과 로컬 영속 저장을 구현했습니다. 일주월 통계, 히트맵, D-Day, 뽀모도로, 생활 루틴, 비교 리포트, 개인정보 내보내기·삭제도 실행 가능합니다.

## 부분 구현·미검증

- Supabase Auth·스냅샷 백업/복원/삭제 어댑터 및 SQL/RLS 제공. 실제 프로젝트·이메일 로그인·두 계정 RLS는 미검증입니다. UI는 설정이 없으면 미연결로 표시합니다.
- 정상화 DB 테이블은 후속 API를 위한 스키마이며 현재 UI는 `user_workspaces` 스냅샷만 사용합니다. 자동 동기화·충돌 병합·원격 이벤트별 검증 서버가 없습니다.
- 그룹 생성·코드 확인·공유 선택·목표·체크인은 **동일 브라우저의 가상 시뮬레이션**입니다. 다른 사람의 상태나 기기 간 초대를 표시하지 않습니다. 실제 그룹 권한, Realtime, 선택형 랭킹·공동 챌린지는 미구현입니다.
- 규칙 코치는 LLM·ML 모델이 아닙니다. 연구 데이터·효과 검증 결과가 없습니다. 맞춤 계획도 단순 목표 분할 제안입니다.
- Android 앱/UsageStats, iOS 시스템 사용량, 다른 앱 차단, 카메라/타임랩스/WebRTC, 웨어러블/위젯, 외부 캘린더/음악, Chrome 확장은 미구현입니다.
- FastAPI는 두지 않았습니다. 동일 TypeScript 도메인을 로컬 UI와 테스트가 공유하며 REST/OpenAPI 서버는 없습니다.
- 보고서 점수는 현재 데이터로 계산하며 생성 당시 결과를 별도 영구 저장하지 않습니다. 전주 대비 웰빙 점수 그래프는 없고 원지표 전후 비교를 제공합니다.
- 뽀모도로 집중/휴식은 수동 전환입니다. 종료 시 설정 시간까지만 기록합니다. 브라우저를 닫은 상태의 예약 알림은 없습니다.
- 브라우저·기기 시각을 사용하므로 시각 조작의 완전 방지/기기 간 정확도 보장은 없습니다. 날짜는 브라우저 현지 시간대이며 별도 시간대 변경 UI는 없습니다.
- 서비스 워커/PWA 설치·오프라인 배포 캐시는 미구현입니다. 로컬 서버를 실행하면 인터넷 없이 핵심 기능을 사용할 수 있습니다. 원격 페이지의 첫 접속에는 네트워크가 필요합니다.
- 자동 보존 기간, 계정 자체 탈퇴, 배포 운영·법적 절차·실사용자 연구 승인은 완료하지 않았습니다. 공개 실사용 서비스로 운영하기 전 별도 검토가 필요합니다.
- Chrome 데스크톱과 390px 모바일 뷰로 검증합니다. 실제 Android/iOS 기기, Safari, 보조공학 기기 및 WCAG 전체 인증은 수행하지 않았습니다.

## 다음 작업 우선순위

1. Supabase 실제 프로젝트를 연결하고 두 계정의 정상/비정상 RLS 접근과 이메일 복구를 검증.
2. 정상화 이벤트 API, 서버 측 중복/구간 검증 및 기기 간 충돌 처리를 구현.
3. 실제 그룹 RPC/Realtime·탈퇴·비회원 차단·신고 흐름 검증.
4. Android SDK와 실제 기기를 준비해 권한 거부/허용/철회 흐름부터 구현.
5. 동의 기반 소규모 사용성 연구와 지표 개선.
