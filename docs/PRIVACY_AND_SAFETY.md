# 개인정보와 사용자 선택

## 기본 수집

닉네임·자기 설정 목표·공부 구간·계획·할 일·선택적 사용 이유·생활 루틴을 브라우저에 저장합니다. 실명·학교·위치·연락처·마이크·카메라는 요구하지 않습니다. 자동 앱 사용량 수집과 강제 차단을 하지 않습니다. 사용 이유는 ‘기타’를 고를 수 있고 사용 습관 기록 없이 학습 기능을 사용할 수 있습니다.

로컬은 해당 브라우저/OS 계정의 접근 범위입니다. 자체 비밀번호나 암호화 저장소가 아니므로 공동 기기에서 다른 사용자가 볼 수 있습니다. 현재 모드만 삭제하거나 JSON/CSV로 내보낼 수 있습니다. 브라우저 전체 사이트 데이터 삭제 시 두 모드가 모두 삭제될 수 있습니다.

자동 보존 기간/30일 삭제 기능은 아직 없으며, 기록은 직접 삭제하거나 브라우저 저장소가 제거될 때까지 남습니다. 원시 자동 수집을 하지 않습니다. 인터넷이 연결되어 있으면 글꼴 제공자에게 웹폰트 요청이 발생할 수 있으며, 기록 내용은 요청에 포함하지 않습니다. 외부 AI·광고 분석 SDK는 사용하지 않습니다.

## 선택 계정

Supabase를 구성한 경우 이메일 인증에 이메일을 사용합니다. 로그인만으로 로컬 기록을 업로드하지 않습니다. 개인 모드에서 사용자가 백업 버튼을 눌러야 payload를 전송합니다. 가상 모드에서는 업로드를 막습니다. RLS로 본인 행만 접근하도록 SQL을 제공했으나 실서비스 검증은 미실행입니다.

온라인 기록 삭제와 로컬 기록 삭제는 별개이며 화면에서 안내합니다. 인증 계정 자체 탈퇴, 자동 보존 기간, 운영자 감사·악용 방지·배포 전 동의 절차는 후속 작업입니다. 서비스 역할 비밀 키를 클라이언트 코드에 넣으면 안 됩니다.

## 그룹과 알림

현재 그룹은 명시적으로 표시된 로컬 시뮬레이션이며 외부로 상태를 공유하지 않습니다. 공유 설정은 OFF로 시작하고 언제든 변경하거나 그룹을 나갈 수 있습니다. 실제 다른 사용자 검색·메시징·공개 랭킹이 없으므로 신고/차단 기능은 아직 없습니다. 실시간 소셜 기능 도입 전에 권한·신고·차단·운영 설계를 추가해야 합니다.

알림은 기본 OFF, 사용자 동작으로 브라우저 권한을 요청하며 현재 열린 앱의 뽀모도로 종료에 한정합니다. 앱을 닫은 뒤 푸시 알림이나 감시는 없습니다. 연구 스위치는 자동 전송 동의가 아니며 익명 닉네임 없는 CSV를 수동으로 내보내는 흐름입니다. CSV에는 시간·활동명이 포함되므로 공유 전 재식별 가능성을 검토해야 합니다.

코치는 진단/치료를 하지 않고, 비난·강압·수면 박탈·끝없는 순위 경쟁을 사용하지 않습니다. 자발적 기록과 사용자의 선택을 우선합니다.
