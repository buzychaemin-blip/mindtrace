# 3분 시연

시작 전: 가상 모드 배너 확인. 브라우저에서 온보딩 완료. 타이머가 실행 중이면 종료. 실제 효과를 보여주는 연구 결과가 아니라 기능 시연임을 먼저 설명합니다.

| 시간 | 화면/동작 | 말하기 |
|---|---|---|
| 0:00–0:25 | 오늘의 균형 | “공부하려고 스마트폰을 켰는데 습관적으로 다른 앱을 본 적이 있습니다. MindTrace는 공부 시간뿐 아니라 사용 이유와 휴식을 함께 돌아보게 합니다. 지금은 가상 데이터 시연입니다.” |
| 0:25–0:55 | 집중 타이머 시작→일시정지→종료, 플래너 | “과목별로 기록하고 10분 단위 계획을 세웁니다. 타이머는 실제 시각과 중단 구간을 저장해 새로고침해도 이어집니다.” |
| 0:55–1:25 | 디지털 습관 → 40분 사용 직접 입력 | “웹에서는 다른 앱을 감시하지 않습니다. 사용자가 활동·시간·이유를 선택해 기록하고 나중에 수정하거나 지울 수 있습니다.” |
| 1:25–2:05 | 마인드 코치 → 근거 → 실천 담기 | “30분 이상 기록이 생기면 긴 사용 패턴을 알려줍니다. 현재 코치는 규칙 기반이며 외부 AI로 데이터를 보내지 않습니다. 제안의 근거를 보고, 고치거나 거절할 수 있습니다.” |
| 2:05–2:35 | 작은 실천/주간 리포트 | “기록이 없는 항목은 0점으로 취급하지 않고 계산에서 제외합니다. 지난 7일과 비교하지만 이것을 실제 개선 효과나 진단으로 주장하지 않습니다.” |
| 2:35–3:00 | 함께하는 공부/설정 | “순위 경쟁 대신 공동 목표와 비공개 기본값을 설계했습니다. 현재 그룹은 브라우저 안의 가상 시연이고, 실제 다중 사용자 연결은 후속 과제입니다. 개인 기록은 직접 내보내거나 삭제할 수 있습니다.” |

## 예상 질문

- “AI가 맞나요?” → “지금 구현은 근거를 설명하는 규칙 엔진입니다. 데이터가 없는 상태의 결론을 피하는 것이 우선이며, 충분한 동의 데이터와 검증 후 모델을 확장할 계획입니다.”
- “앱을 차단하나요?” → “웹앱은 다른 앱을 차단하지 않습니다. 수동 기록과 집중 화면을 제공하며, Android 사용 통계는 별도 권한 기반 후속 구현입니다.”
- “기존 공부 앱과 무엇이 다른가요?” → “공부량 경쟁보다 사용 이유, 휴식, 자기 목표를 연결하고 내가 실천을 선택하도록 설계했습니다.”
- “효과가 있나요?” → “실제 효과는 아직 검증하지 않았습니다. 향후 자발적 참가자의 전후 지표와 자기평가를 비교하고 누락·편향·인과 한계를 함께 보고하겠습니다.”
